# Locating Pins and Dowel Pins

## Dataset

- **Source:** [Innerscene pins and retaining rings](https://www.innerscene.com/tools/library/3d-parts?tag=hardware&type=rings-pins)
- **Models listed:** 24 pins and retaining rings together
- This is not a count of locating pins alone. Check each model’s page for its type, size, and available file types.

## Where they are used

A locating or dowel pin fits into matching holes in two parts. It helps keep the parts lined up in the same position. These pins are used in machine tools, molds, drill guides, and fixtures. They are useful when parts need to be taken apart and put back together in the same position.
