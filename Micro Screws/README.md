# Micro Screws

## CAD model source: Innerscene

- **Dataset page:** [Screws and bolts](https://www.innerscene.com/tools/library/3d-parts?tag=hardware&type=screws-bolts)
- **Models:** Metric and UNC screw and bolt models, with individual browser previews and downloads. The listing includes sizes such as M2 and M2.5; it does not confirm that every model is a micro-sized part.
- **Format:** The library offers STEP and other 3D formats.
- **Licence:** The library describes the files as public domain. Check the individual model page and attribution details before redistributing.
- **ZIP in this repository:** None; no model files have been downloaded or added.
