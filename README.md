# Micro-Components CAD Dataset

A curated repository for small mechanical and electrical components, intended for CAD study, layout, and prototyping.

## Dataset status

The repository currently contains **no CAD model files**. The original repository contained only a short README. No downloaded model could be included in this update with redistribution rights established from a clear, applicable licence. Vendor catalogue downloads and model previews are not treated as permission to redistribute.

Each category folder explains the component and its uses, and records this limitation. These folders are documentation only; they are not presented as a completed CAD dataset. No STEP/STP, STL, or other geometry is included.

## Formats and downloading

There are currently no CAD formats to download. When licensed models are added, STEP (.step/.stp) is preferred for editable solid geometry. GitHub's **Code → Download ZIP** downloads the repository contents, including any CAD files later added.

## Redistribution and use

Only models with an explicit licence permitting redistribution should be added. Preserve each source's attribution and licence terms beside the model. A source page offering a free download is not, by itself, a redistribution licence. Verify downloaded files open in a STEP-capable CAD application before describing them as usable models.

## Contributions

Contributions of original models or models with clear redistribution rights are welcome. Include the source, licence, attribution, units, and a brief verification note with each addition.
