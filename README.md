# Micro-Components CAD Dataset

This repository organizes CAD model sources for small mechanical parts. The links below go to Innerscene, where models can be viewed and downloaded individually.

## Dataset status

The CAD models are hosted on Innerscene; they are not stored in this GitHub repository. The number beside each category is the number of models listed by Innerscene. It may include models that are larger than micro-sized, so check the model page for dimensions and available file formats.

## Categories and model counts

1. **[Micro Screws — 65 models](https://www.innerscene.com/tools/library/3d-parts?tag=hardware&type=screws-bolts)**  
   Used to fasten small parts in electronics, sensors, instruments, and compact machines.

2. **[Micro Nuts — 45 models](https://www.innerscene.com/tools/library/3d-parts?tag=hardware&type=nuts)**  
   Used with threaded screws or rods to hold small assemblies together.

3. **[Washers and Shims — 19 washer models](https://www.innerscene.com/tools/library/3d-parts?tag=hardware&type=washers)**  
   Washers spread pressure under a screw or nut. This collection does not have a separate shim category.

4. **[Locating Pins and Dowel Pins — 24 models](https://www.innerscene.com/tools/library/3d-parts?tag=hardware&type=rings-pins)**  
   This count combines pins and retaining rings; it is not a count of locating pins alone. Pins help align parts in tools, molds, and machine fixtures.

5. **[Micro Springs — 5 models](https://www.innerscene.com/tools/library/3d-parts?tag=hardware&type=springs)**  
   Springs return moving parts to position or apply pressure in switches, buttons, and small mechanisms.

6. **[Miniature Bearings — 18 models](https://www.innerscene.com/tools/library/3d-parts?tag=hardware&type=bearings)**  
   Bearings help shafts turn smoothly in motors, fans, robots, and instruments.

7. **[Micro Gears — 37 gear and gearbox models](https://www.innerscene.com/tools/library/3d-parts/tag/mechanical)**  
   Gears transfer turning motion in clocks, instruments, small motors, and compact machines.

## Downloading models

Open a category link, choose a model, and use the download option on its page. Models are downloaded individually, not as one ZIP per category. Available formats differ by model; check its page for details.

## Licence and reuse

Innerscene describes its library models as public domain. Check the licence information on each model page before reusing or redistributing a file.

## Contributing

When adding a model to this repository, include its source link, licence, attribution, dimensions, file format, and a note confirming that it opens in CAD software.
